================================================================================
IF SOMETHING GOES WRONG
================================================================================

Dashboard shows "Loading..." forever?
→ Check browser console (F12) for error messages
→ Make sure npm start shows the startup messages
→ Try http://localhost:3000/api/data in browser

Port 3000 already in use?
→ Windows: netstat -ano | findstr :3000
          taskkill /PID [number] /F
→ Mac: lsof -ti:3000 | xargs kill -9

No data showing?
→ Open http://localhost:3000/api/data in browser
→ If blank, check your Google Sheet has data
→ Share what you see and I'll help
